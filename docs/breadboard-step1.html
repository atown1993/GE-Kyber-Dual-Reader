Step 1 — one RDM6300 reader on the HW-724 ESP32, wired on its FINAL pins

Reader A only. Every wire here stays exactly where it is for the rest of the build — step 3 only ADDS reader B and the LEDs. The 2N7000 goes in now so reader A's ground never has to move; the step-1 sketch simply holds its gate high. Sketch: arduino/step1_bringup/step1_bringup.ino. Wire colors: red = +5V, grey = GND, yellow = RDM TX, green = divider tap → SVP, blue = MOSFET gate, purple = antenna.

Wire map — from → to by hole, keyed to pin function

Run these first / notes

  • Rails: top pair = 5V / GND. Bottom GND rail is bridged to the top one. (The bottom + rail becomes 3V3 in step 3 — leave it empty now.)
  • Reader GND does NOT go to the rail. It goes to the 2N7000 drain; the MOSFET's source goes to GND; the gate goes to GPIO0 (right column, pin 5). The sketch drives the gate high, so the reader is simply on.
  • 2N7000 pinout, flat face toward you, legs left→right: S · G · D.
  • The divider is mandatory (ESP32 GPIOs are not 5V tolerant): 10k from TX, 20k to GND, tap between = 3.33V → SVP (left column, pin 1 — the top corner pin).
  • RDM6300 P1 header order is TX·RX·NC·GND·+5V with no silk — confirm GND and +5V with a meter before powering.
  • Coil leads are enamelled — scrape and tin them or the module looks dead.
